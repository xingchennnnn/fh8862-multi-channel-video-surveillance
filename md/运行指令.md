# RTSPserver_V6 运行指令

## 网络约定

当前代码是四路摄像头版本，网页、Node.js 服务和 MediaMTX 配置中固定使用以下地址：

```text
虚拟机 Ubuntu: 192.168.1.1
开发板 Camera 1: 192.168.1.11
开发板 Camera 2: 192.168.1.12
开发板 Camera 3: 192.168.1.13
开发板 Camera 4: 192.168.1.14
```

如果只有一块开发板，建议按 `cmd.txt` 配成 `192.168.1.12`，Windows 页面中查看 `Camera 2`。

## 一、虚拟机 Ubuntu：编译和部署

进入工程目录：

```bash
cd /mnt/hgfs/share/RTSPserver_V6/RTSPserver_V6/RTSPserver
```

编译并复制 `demo` 到 NFS 目录：

```bash
./make.sh
```

`make.sh` 当前内容等价于：

```bash
make clean
make
cp demo /mnt/nfs_share/
rm demo -rf
```

复制开发板运行需要的驱动和 ISP 参数文件：

```bash
mkdir -p /mnt/nfs_share/driver
cp -a driver/* /mnt/nfs_share/driver/
cp lib/imx415_mipi_attr.hex /mnt/nfs_share/
```

## 二、开发板：串口执行

### 单板 Camera 2 示例

```bash
ifconfig eth0 192.168.1.12
mount -t nfs 192.168.1.1:/mnt/nfs_share /mnt -o nolock

cd /mnt/driver
sh load_modules_FH8862.sh

cp /mnt/imx415_mipi_attr.hex /home/

cd /mnt
./demo
```

启动成功后，开发板会监听：

```text
RTSP: 8554
控制端口: 9999
主码流: rtsp://192.168.1.12:8554/main
子码流: rtsp://192.168.1.12:8554/sub
```

注意：正常 RTSP/Web 预览和控制只需要执行 `./demo`。`main.c` 中说明 `./demo <IP>` 会额外启用 PES UDP 推流，存在稳定性风险，常规运行不建议加 IP 参数。

## 三、虚拟机 Ubuntu：启动Web服务

进入 Web 目录：

```bash
cd /mnt/hgfs/share/RTSPserver_V6/RTSPserver_V6/RTSPserver/web
```

首次运行或缺少依赖时，安装 `iconv-lite`：

```bash
npm install iconv-lite
```

启动 MediaMTX 和前端 HTTP 服务：

```bash
./start.sh
```

启动成功后会显示类似信息：

```text
Frontend: http://192.168.1.1:8080
WHEP API: http://192.168.1.1:8889/main/whep
Mediamtx API: http://192.168.1.1:9997
```

当前 `web/mediamtx.yml` 已固定配置四路地址 `192.168.1.11` 到 `192.168.1.14`，`./start.sh <板端IP>` 参数不会改变网页和 Node.js 中的四路固定地址，通常直接执行 `./start.sh` 即可。

停止 Web 服务：

```bash
cd /mnt/hgfs/share/RTSPserver_V6/RTSPserver_V6/RTSPserver/web
./stop.sh
```

## 四、Windows：浏览器访问

在 Windows 浏览器打开：

```text
http://192.168.1.1:8080
```

如果只有一块 `192.168.1.12` 的开发板，页面中查看 `Camera 2`；`Camera 1`、`Camera 3`、`Camera 4` 连接失败属于正常现象。

也可以用 VLC 直接验证 RTSP：

```text
rtsp://192.168.1.12:8554/main
rtsp://192.168.1.12:8554/sub
```

四路板全部运行时，对应 RTSP 地址为：

```text
rtsp://192.168.1.11:8554/main
rtsp://192.168.1.11:8554/sub

rtsp://192.168.1.12:8554/main
rtsp://192.168.1.12:8554/sub

rtsp://192.168.1.13:8554/main
rtsp://192.168.1.13:8554/sub

rtsp://192.168.1.14:8554/main
rtsp://192.168.1.14:8554/sub
```

## 五、常用检查命令

虚拟机检查 Web 和 MediaMTX 端口：

```bash
lsof -i:8080
lsof -i:8889
lsof -i:9997
```

虚拟机查看日志：

```bash
cd /mnt/hgfs/share/RTSPserver_V6/RTSPserver_V6/RTSPserver/web
tail -f server.log
tail -f mediamtx.log
```

开发板检查网络：

```bash
ifconfig eth0
ping 192.168.1.1
```
